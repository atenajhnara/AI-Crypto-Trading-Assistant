# 🤖 Smart Crypto Trading Assistant
یک دستیار هوشمند ترید کریپتو با تولید سیگنال‌های BUY / SELL / WAIT

---

## 🧠 توضیحات فارسی

این پروژه یک اسکریپت پایتون است که سیگنال‌های ساده خرید، فروش یا انتظار برای BTC/USDT روی Bybit Futures تولید می‌کند.  
اندیکاتورهای تکنیکال استفاده شده شامل MA50، MA200، RSI و MACD هستند و خروجی به صورت جدول در ترمینال نمایش داده می‌شود.

---

### ✳️ ویژگی‌ها / Features

- اتصال به Bybit Futures و دریافت داده کندل‌ها  
- محاسبه اندیکاتورهای MA50، MA200، RSI و MACD  
- تولید سیگنال ساده BUY / SELL / WAIT  
- نمایش آخرین سیگنال‌ها همراه با مقادیر اندیکاتورها
